Copy the CONTENTS of your original USRDIR/data directory into this Data folder.

eboot.bin
Data/
  lumendata/packed/...
  don3d/...
  sound/...
  font/font.ttf (or the installation's OTF/TTC font)

Do not add an extra Data/data level. Preserve the original subfolder and file names.
On the PS5 this folder is /app0/Data.
Settings, accounts, scores and caches use /data/Waddamburo.
No arcade assets are supplied by this port.
